    Verification & Honest Limitations

    Automated checks enforced in scripts/benchmark.py & verify_results.py

    • Warm-start scope: Evaluates users with ≥3 training reviews and held-out items present in the training-positive catalog. Cold-start users/items are excluded and tracked in run.json.
    • Inferred product hints: Because Amazon 2014 metadata (titles/images) was not downloaded for this pilot, category tags and keywords in this UI are inferred strictly from training-window review summaries (never test reviews) and linked directly to Amazon ASIN pages.
    • Review proxy: Ratings ≥4 serve as implicit positive feedback; unreviewed items are not verified negatives.

    Reproduce Locally

    Run the full benchmark, report builder, verification checks, and demo data export from scratch

    git clone https://github.com/FaisalKabirGalib/StyleMatch.git
cd StyleMatch
uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/download_data.py
.venv/bin/python scripts/benchmark.py
.venv/bin/python scripts/build_report.py
.venv/bin/python scripts/verify_results.py
.venv/bin/python scripts/build_demo_data.py
